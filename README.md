# AI Developer Assistant
Python project to learn the development AI-powered developer assistant using an LLM.

## Features
- Explain code
- Find bugs
- Improve code
- Generate test cases

## Requirements
Python 3.12+

## Goals
The goal of this project is to learn:
- Python
- Software development
- Prompt engineering
- LLM integration
- LLM evaluation
- RAG
- Structured outputs
